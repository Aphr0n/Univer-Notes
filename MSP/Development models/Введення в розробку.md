Розробка ПЗ складається з ~6 етапів:
- Analysis - З'ясування вимог замовника
- Specification - Створення специфікації(вимог до системи)
- System Design - Ствоерння загальної архітектури програми, її компонентів та взаємодії між ними
- Module Design - Детальне проектування модулів
- Coding - Написання коду проекту
- Integration - Об'єднання модулів в одну систему
