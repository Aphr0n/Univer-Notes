**ROC (Receiver Operating Characteristic)** — це графік, який показує залежність між $TPR$ (вісь $Y$) та $FPR$ (вісь $X$) при зміні порога класифікації.

# Як виглядає хороша ROC-крива?
1. **Perfect Performance:** Ідеальна модель ($TPR = 1$, $FPR = 0$).
2. **Random Guessing:** Випадковий класифікатор (крива проходить по діагоналі).
3. **Реальна модель:** Чим ближче крива до верхнього лівого кута, тим краще.

# AUC — Area Under the Curve
**AUC** — це площа під ROC-кривою, яка оцінює загальну здатність моделі розрізняти два класи:

| AUC           | Інтерпретація                        |
| :------------ | :----------------------------------- |
| **1.0**       | Ідеальне розділення                  |
| **0.9–1.0**   | Дуже добре                           |
| **0.8–0.9**   | Добре                                |
| **0.7–0.8**   | Прийнятно                            |
| **0.5**       | Приблизно як випадковий класифікатор |
| **Менше 0.5** | Гірше випадкового ранжування         |
