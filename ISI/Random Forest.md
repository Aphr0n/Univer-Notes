Random Forest — це груповий алгоритм (Ensemble Learning), який використовує багато дерев рішень.

Замість одного дерева ми створюємо цілий ліс дерев.
![[Pasted image 20261126005951.png]]

Наприклад:
- дерево №1 прогнозує клас A;
- дерево №2 прогнозує клас B;
- дерево №3 прогнозує клас A;
- дерево №4 прогнозує клас A;
- дерево №5 прогнозує клас B.
Random Forest збирає результати всіх дерев і вибирає результат, який отримав найбільше голосів.

Це називається *Majority Voting*.

У прикладі:
- A отримав 3 голоси;
- B отримав 2 голоси.
Отже, результат — A.

# Принцип роботи алгоритму
1. Bootstrap 
	Випадково вибираємо підмножину навчальних даних із поверненням (with replacement). Це означає, що один і той самий зразок може потрапити до вибірки декілька разів.

2. Створення дерева
	Навчаємо дерево рішень на вибраній підмножині даних. Додатково вибираємо підмножину ознак без повернення (without replacement).

3. Повторення 
	Повторюємо перші два кроки багато разів. Наприклад, створюємо 100 дерев.

4. Агрегація
	Об'єднуємо результати всіх дерев. Для класифікації зазвичай використовується Majority Voting.

# Переваги й недоліки
|**Переваги**|**Недоліки**|
|---|---|
|Менша схильність до перенавчання порівняно з окремим деревом у багатьох задачах|Більша обчислювальна складність|
|Хороша якість класифікації|Потрібно зберігати багато дерев|
|Не вимагає настільки детального налаштування, як окреме дерево|Складніше пояснити кінцеве рішення, ніж рішення одного дерева|
|Добре працює з багатьма типами табличних даних||
