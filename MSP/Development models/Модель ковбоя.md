**Cowboy Coding** — програмування без чіткого плану, формальних вимог і належної організації.

Це найпростіший підхід:
1. Пишемо код.
2. Знаходимо помилку.
3. Виправляємо помилку.
4. Знову пишемо код.
5. Повторюємо цикл.

| Переваги                       | Недоліки                                    |
| ------------------------------ | ------------------------------------------- |
| Простота підходу               | Слабкий і складний контроль проєкту         |
| Можливість швидко створити MVP | Відсутність формалізованих вимог до проєкту |
|                                | Відсутність формалізованої архітектури      |
