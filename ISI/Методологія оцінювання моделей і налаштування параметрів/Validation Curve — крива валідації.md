Наприклад, для SVM перевіримо, як змінюється точність залежно від параметра $C = [0.01, 0.1, 1, 10, 100]$. Для кожного значення:
1. Навчаємо модель.
2. Визначаємо точність на Training.
3. Визначаємо точність на Validation.
4. Будуємо графік.

**Як читати Validation Curve?**
- Якщо обидві точності низькі — можливо, модель недонавчена.
- Якщо Training Accuracy висока, а Validation Accuracy низька — можливе перенавчання.
- Якщо Validation Accuracy максимальна — це хороша область значень параметра.

**Основна мета:** знайти значення параметра, при якому модель найкраще працює на невідомих даних.
