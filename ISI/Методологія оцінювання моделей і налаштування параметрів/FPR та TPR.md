# FPR — False Positive Rate
Частка негативних об'єктів, які модель помилково класифікувала як позитивні (показує, як часто модель помилково б'є на тривогу):

$$FPR = \frac{FP}{FP + TN}$$

У нашому прикладі:
$$FPR = \frac{5}{5 + 45} = 0.1 = 10\%$$

# TPR — True Positive Rate (Recall / Sensitivity)
Частка позитивних об'єктів, які модель правильно знайшла:

$$TPR = \frac{TP}{TP + FN}$$

У нашому прикладі:
$$TPR = \frac{40}{40 + 10} = 0.8 = 80\%$$
