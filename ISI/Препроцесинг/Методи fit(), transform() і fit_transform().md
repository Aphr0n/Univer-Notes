# fit() — навчитися на даних

Алгоритм аналізує дані та визначає параметри, які потрібні для подальшої обробки.

Наприклад, знаходить середнє значення стовпця:

`10, 20, 30, 40`

Середнє = 25.

>[!warning] fit() в препроцесорах сам по собі не змінює дані

# transform() — застосувати отримані параметри
Функція застосовує значення отримані через *fit()* до датасету

# fit_transform() — виконати обидві операції послідовно.


# Python
```python
import numpy as np
from sklearn.impute import SimpleImputer

# Наші дані
X = np.array([
    [10],
    [20],
    [np.nan],
    [40],
    [30]
])

print(X)

# fit()
imputer = SimpleImputer(strategy="mean")
imputer.fit(X)
# transform()
X_new = imputer.transform(X)
print(X_new)
```

# **Найважливіше правило: fit і transform**
Якщо тренувальні й тестувальні дані нормалізувати окремо, однакові початкові значення можуть отримати різні результати. Це порушує правильну процедуру оцінювання моделі. Тому параметри обробки потрібно визначати лише на тренувальних даних.
