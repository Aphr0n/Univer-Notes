# Confusion Matrix — матриця помилок (змішування)
**Confusion Matrix** — це таблиця, яка порівнює справжні класи з передбаченими. У матриці є чотири основні значення:
1. **TP (True Positive)** — правильно передбачений позитивний клас (людина хвора — модель сказала, що хвора).
2. **TN (True Negative)** — правильно передбачений негативний клас (людина здорова — модель сказала, що здорова).
3. **FP (False Positive)** — хибнопозитивний результат (людина здорова — модель сказала, що хвора).
4. **FN (False Negative)** — хибнонегативний результат (людина хвора — модель сказала, що здорова).

| Справжній стан | Передбачення | Результат |
| :------------- | :----------- | :-------- |
| Positive       | Positive     | **TP**    |
| Positive       | Negative     | **FN**    |
| Negative       | Positive     | **FP**    |
| Negative       | Negative     | **TN**    |

**Приклад із числами (100 пацієнтів):**

|                       | Передбачено хворобу | Передбачено здоров'я |
| :-------------------- | :------------------ | :------------------- |
| **Хворі насправді**   | 40 (TP)             | 10 (FN)              |
| **Здорові насправді** | 5 (FP)              | 45 (TN)              |

Отримуємо: $TP = 40$, $FN = 10$, $FP = 5$, $TN = 45$.

# Error Rate — частота помилок
Показує, яка частина передбачень була неправильною:

$$ERR = \frac{FP + FN}{FP + FN + TP + TN} = \frac{\text{кількість помилок}}{\text{загальна кількість прогнозів}}$$

У нашому прикладі:
$$ERR = \frac{5 + 10}{100} = 0.15 = 15\%$$

# Accuracy — точність
Показує, яка частина передбачень була правильною:

$$ACC = \frac{TP + TN}{TP + TN + FP + FN} = 1 - ERR$$

У нашому прикладі:
$$ACC = \frac{40 + 45}{100} = 85\%$$

## Проблема Accuracy при незбалансованих класах
Уявімо 1000 пацієнтів: 990 здорових і 10 хворих. Якщо модель завжди відповідає «Здоровий», то:
$$Accuracy = \frac{990}{1000} = 99\%$$

На перший погляд результат чудовий, але модель не виявила жодного хворого. Тому для незбалансованих класів Accuracy недостатньо.
