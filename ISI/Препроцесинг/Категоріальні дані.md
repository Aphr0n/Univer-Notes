Машинне навчання часто працює з числами, але в реальних таблицях є не тільки числа, а й текстові значення.

| Вік | Колір автомобіля | Розмір |
| --- | ---------------- | ------ |
| 20  | Червоний         | S      |
| 25  | Синій            | M      |
| 30  | Зелений          | XL     |


# Ординальні дані (Ordinal)

Це категорії, між якими існує природний порядок.

Наприклад, розміри одягу:
- S — маленький;
- M — середній;
- L — великий;
- XL — дуже великий;
- XXL — ще більший.
Цей текст можна перетворити в числа

|**Розмір**|**Число**|
|---|---|
|S|1|
|M|2|
|L|3|
|XL|4|
|XXL|5|
## Python
```python
size_mapping = {
    "S": 1,
    "M": 2,
    "L": 3,
    "XL": 4,
    "XXL": 5
}

df["size"] = df["size"].map(size_mapping)
```


# Номінальні дані (Nominal)

Це категорії, між якими немає природного порядку.

Наприклад:
- червоний;
- зелений;
- синій;
- чорний.
    


Це просто різні категорії.

Якщо ми перетворитмо дані на числа

| Колір    | Число |
| -------- | ----- |
| Червоний | 0     |
| Зелений  | 1     |
| Синій    | 2     |

Алгоритм може сприйняти ці числа як значення з певним порядком: $2 > 1 > 0$ 

Тобто може вирішити, що синій колір більший за зелений, а зелений більший за червоний.


# Кодування класів (Label Encoding)

У презентації також розглядається кодування номінальних позначень класів.

Наприклад, ми створюємо модель, яка визначає стан людини:

| Стан    | Число |
| ------- | ----- |
| Хвора   | 0     |
| Здорова | 1     |
Або модель, яка визначає музичний жанр:

| Жанр      | Число |
| --------- | ----- |
| Pop       | 0     |
| Rock      | 1     |
| Classical | 2     |

Тут можна кодувати класів, тому що це не числові ознаки, за якими модель повинна вимірювати відстань або порівнювати величини, а просто ідентифікатори класів.

# One-Hot Encoding

Замість того щоб присвоювати категоріям числа 0, 1, 2, ми створюємо окремий стовпець для кожної категорії, щоб алгоритм не думав, що червоний більший за зелений.

Наприклад, маємо кольори:
- **Black**
- **Green**
- **Red**

Замість такого кодування:

| Колір | Число |
| :---- | :---: |
| Black |   0   |
| Green |   1   |
| Red   |   2   |

Створюємо три окремі стовпці (метод **One-Hot Encoding**):

| Black | Green | Red |
| :---: | :---: | :-: |
|   1   |   0   |  0  |
|   0   |   1   |  0  |
|   0   |   0   |  1  |

* **Якщо колір чорний:**
  * `Black = 1`
  * `Green = 0`
  * `Red = 0`
* **Якщо колір зелений:**
  * `Black = 0`
  * `Green = 1`
  * `Red = 0`
* **Якщо колір червоний:**
  * `Black = 0`
  * `Green = 0`
  * `Red = 1`

## Python
```python
from sklearn.preprocessing import OneHotEncoder

encoder = OneHotEncoder()

X_train_encoded = encoder.fit_transform(X_train)
X_test_encoded = encoder.transform(X_test)
```
