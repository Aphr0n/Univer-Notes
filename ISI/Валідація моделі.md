Валідація моделі - процес визначення на скілкьки помиляється модель в своїх передбаченнях. Для визначення на скільки модель може помилятися ми використовуємо МАЕ(Mean Absolute Error). Щоб його визначити потрібно спочатку поділити датасет на 2 частини:
- Тренувальна частина
- Частина для перевірки
Сам МАЕ рахується так:
```
error=actual−predicted
```
