# XGBoost
*XGBoost* — алгоритм машинного навчання, заснований на Gradient Boosting.

Його ідея полягає в тому, що багато невеликих дерев рішень послідовно створюються так, щоб наступні дерева виправляли помилки попередніх.
Наприклад:
1. Перше дерево робить прогноз.
2. Обчислюються помилки.
3. Наступне дерево намагається виправити ці помилки.
4. Процес повторюється.
5. Результати дерев комбінуються.

Його часто застосовують у:
- прогнозуванні;
- класифікації;
- фінансах;
- аналізі клієнтів;
- змаганнях із машинного навчання.
# TabNet

TabNet — архітектура глибокого навчання для табличних даних.

Її особливість полягає у використанні механізму уваги (Attention).

Ідея: модель може вибирати, на які ознаки звертати більше уваги під час прийняття рішення.

Наприклад, під час прогнозування ціни квартири модель може враховувати:

- місце розташування;
- площу;
- кількість кімнат;
- поверх.
    

На різних етапах обчислення модель може приділяти різну увагу різним ознакам.

**Різниця:**

| XGBoost                             | TabNet                                     |
| ----------------------------------- | ------------------------------------------ |
| Gradient Boosting                   | Глибоке навчання                           |
| Комбінація дерев                    | Нейронна архітектура                       |
| Послідовне виправлення помилок      | Attention до ознак                         |
| Дуже популярний для табличних даних | Спеціально розроблений для табличних даних |

Не варто вважати, що TabNet завжди кращий за XGBoost. Якість залежить від конкретного датасету та задачі.
