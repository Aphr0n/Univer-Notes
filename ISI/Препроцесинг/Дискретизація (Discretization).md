Дискретизація — це перетворення неперервних числових значень на окремі категорії або інтервали. Наприклад, маємо вік людей: `15`, `18`, `23`, `35`, `48`, `67`, `75`.

Можемо розділити вік на групи (метод **Binning** / **дискретизація**):

| Вік | Категорія |
| :-: | :-------- |
| 15  | Дитина    |
| 18  | Молодь    |
| 23  | Молодь    |
| 35  | Дорослий  |
| 48  | Дорослий  |
| 67  | Пенсіонер |
| 75  | Пенсіонер |

Або записати математично:

$$
\begin{aligned}
0\text{–}17 &\rightarrow 1 \\
18\text{–}30 &\rightarrow 2 \\
31\text{–}60 &\rightarrow 3 \\
61+ &\rightarrow 4
\end{aligned}
$$

Тобто замість точного віку ми використовуємо категорію.

* **Перевага:** іноді так легше виявляти закономірності.
* **Недолік:** ми втрачаємо точну інформацію.

> Наприклад, люди віком 31 і 60 років опиняться в одній категорії, хоча між ними значна різниця.

# Python
```python
import pandas as pd

ages = [15, 18, 23, 35, 48, 67, 75]

categories = pd.cut(
    ages,
    bins=[0, 17, 30, 60, float('inf')],
    labels=["Дитина", "Молодь", "Дорослий", "Пенсіонер"]
)

print(categories)

categories = pd.cut(
    ages,
    bins=[0, 17, 30, 60, float('inf')],
    labels=[1, 2, 3, 4]
)

print(categories)
```
