**Model Selection** — це процес вибору найкращої моделі або конфігурації моделі для конкретної задачі.

Наприклад, ми хочемо класифікувати електронні листи на:
- **Spam**;
- **Not Spam**.

Можемо використати:
- Logistic Regression;
- SVM;
- Decision Tree;
- Random Forest.

Потрібно навчити моделі, перевірити їх та порівняти результати.

## 2.1. Гіперпараметри
**Гіперпараметри** — це налаштування моделі, які задаються до її навчання або оптимізуються окремо від процесу навчання.

Наприклад:
- **Для SVM:**
  - `C` — визначає силу регуляризації;
  - `gamma` — визначає вплив окремих навчальних точок для RBF-ядра.
- **Для Decision Tree:**
  - `max_depth` — максимальна глибина дерева;
  - `min_samples_split` — мінімальна кількість об'єктів для поділу вузла.
- **Для Random Forest:**
  - `n_estimators` — кількість дерев;
  - `max_features` — кількість ознак, які розглядаються під час пошуку поділу.

## 2.2. Grid Search та Random Search
*На сторінці 4 показано два способи пошуку гіперпараметрів.*

### Grid Search (пошук по сітці)
Ми заздалегідь визначаємо значення параметрів і перевіряємо всі можливі комбінації.

Наприклад:
```python
C = [0.1, 1, 10]
gamma = [0.01, 0.1, 1]
```

Маємо:
$$3 \times 3 = 9$$

Тобто потрібно перевірити 9 комбінацій:

| `C` | `gamma` |
| :--- | :--- |
| 0.1 | 0.01 |
| 0.1 | 0.1 |
| 0.1 | 1 |
| 1 | 0.01 |
| 1 | 0.1 |
| 1 | 1 |
| 10 | 0.01 |
| 10 | 0.1 |
| 10 | 1 |

Після цього вибираємо комбінацію з найкращим результатом.

### Random Search (випадковий пошук)
Замість перевірки всіх комбінацій алгоритм випадково вибирає деякі комбінації параметрів.

**Переваги:**
- Може бути швидшим.
- Не потрібно перевіряти всі комбінації.
- Добре підходить для великої кількості гіперпараметрів.

**Недолік:**
- Не гарантує перевірку найкращої комбінації.

### Головна різниця

| Grid Search | Random Search |
| :--- | :--- |
| Перевіряє всі задані комбінації | Перевіряє випадкові комбінації |
| Повний перебір сітки | Обмежена кількість спроб |
| Може бути повільним | Часто швидший |
| Не пропускає точки заданої сітки | Може пропустити оптимальну точку |
