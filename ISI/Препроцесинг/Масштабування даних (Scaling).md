Scaling — це приведення числових значень до порівнянних масштабів.


Розглянемо приклад. Маємо дані про людей:

| Людина | Вік | Зарплата |
| :----: | :-: | :------: |
| **A**  | 20  |   1000   |
| **B**  | 30  |   2000   |
| **C**  | 40  |   3000   |
| **D**  | 50  |   4000   |

#### Проблема:
* **Вік** має значення від `20` до `50`.
* **Зарплата** має значення від `1000` до `4000`.

Тобто зарплата має набагато більші числові значення. Алгоритм, який використовує відстані між точками, може надати зарплаті непропорційно великий вплив.

> Щоб уникнути цього, використовують **масштабування** (Feature Scaling).

Є 2 основні способи:
1. **Normalization** (нормалізація).
2. **Standardization** (стандартизація).

# Нормалізація
Нормалізація - приведення значень до діапазону $[0, 1]$. Тобто після перетворення всі значення будуть знаходитися між `0` і `1`.

Для цього використовується метод **Min-Max Scaling**.

#### Формула:

$$x_{norm}^{(i)} = \frac{x^{(i)} - x_{min}}{x_{max} - x_{min}}$$

Розберімо її:
* $x^{(i)}$ — початкове значення;
* $x_{min}$ — мінімальне значення;
* $x_{max}$ — максимальне значення.

---

#### Приклад

Маємо числа: `10`, `20`, `30`, `40`, `50`.
* **Мінімум** = `10`
* **Максимум** = `50`

Розрахунок для числа `30`:

$$x_{norm} = \frac{30 - 10}{50 - 10} = \frac{20}{40} = 0.5$$

Для всіх значень:

| Початкове значення | Після нормалізації |
| :----------------: | :----------------: |
|         10         |         0          |
|         20         |        0.25        |
|         30         |        0.5         |
|         40         |        0.75        |
|         50         |         1          |
```python
from sklearn.preprocessing import MinMaxScaler

mms = MinMaxScaler()

X_train_norm = mms.fit_transform(X_train)
X_test_norm = mms.transform(X_test)
```

# Стандартизація (Standardization)
Стандартизація — це інший спосіб масштабування. На відміну від нормалізації, ми не обмежуємо всі значення діапазоном від 0 до 1.

Ми перетворюємо дані так, щоб:
- середнє значення було приблизно 0;
- стандартне відхилення було приблизно 1.
## Формула
$$
x_{std}^{(i)} =
\frac{x^{(i)}-\mu_x}{\sigma_x}
$$

Де:
- $x^{(i)}$ — початкове значення;
- $\mu_x$ — середнє арифметичне;
- $\sigma_x$ — стандартне відхилення.
### Приклад стандартизації

 `0`, `1`, `2`, `3`, `4`, `5`.

Після стандартизації 

| Початкове значення | Стандартизоване |
| :----------------: | :-------------: |
|         0          |    -1.336306    |
|         1          |    -0.801784    |
|         2          |    -0.267261    |
|         3          |    0.267261     |
|         4          |    0.801784     |
|         5          |    1.336306     |

* **від'ємні числа** означають значення нижче середнього;
* **`0`** означає середнє;
* **додатні числа** означають значення вище середнього.

---

### Python: `StandardScaler`

```python
from sklearn.preprocessing import StandardScaler

stdsc = StandardScaler()
X_train_std = stdsc.fit_transform(X_train)
X_test_std = stdsc.transform(X_test)
