VAF і AFP: поправка на складність середовища

UFP не враховує, наскільки "важкі" умови проєкту (вимоги до надійності, продуктивності, розподілена обробка тощо). Для цього є 14 питань, кожне оцінюється від 0 (не стосується) до 5 (дуже суттєво).

Формула: 
$$VAF = 0,65 + (∑SMᵢ) / 100$$
де ∑SMᵢ це сума 14 оцінок.
>[!info] поправка змінює результат приблизно від −35% до +35%.

# Питання


| №   | Фактор коригування цінності (VAF)                                                                                      | Значення (0-5) |
| --- | ---------------------------------------------------------------------------------------------------------------------- | -------------- |
| 1   | Чи потребує система надійного резервного копіювання та відновлення?                                                    |                |
| 2   | Чи необхідна передача даних (мережеві комунікації)?                                                                    |                |
| 3   | Чи є функції розподіленої обробки даних?                                                                               |                |
| 4   | Чи є продуктивність критично важливою?                                                                                 |                |
| 5   | Чи працюватиме система в існуючому, сильно завантаженому операційному середовищі?                                      |                |
| 6   | Чи потребує система інтерактивного (on-line) введення даних?                                                           |                |
| 7   | Чи вимагає інтерактивне введення даних, щоб вхідна транзакція формувалася на кількох екранах або за декілька операцій? |                |
| 8   | Чи оновлюються основні файли (майстер-файли) в режимі on-line?                                                         |                |
| 9   | Чи є складними вхідні/вихідні дані, файли або запити?                                                                  |                |
| 10  | Чи є складною внутрішня обробка даних?                                                                                 |                |
| 11  | Чи розроблений код для повторного використання?                                                                        |                |
| 12  | Чи включені конвертація даних та встановлення (монтаж) у проект?                                                       |                |
| 13  | Чи призначена система для кількох встановлень у різних організаціях?                                                   |                |
| 14  | Чи розроблено додаток так, щоб спростити внесення змін та полегшити використання користувачем?                         |                |
|     | **ЗАГАЛОМ (VAF):** $VAF = 0.65 + DI/100$                                                                               |                |
# AFP — скориговані функціональні точки
$$AFP = UFP \times VAF$$
