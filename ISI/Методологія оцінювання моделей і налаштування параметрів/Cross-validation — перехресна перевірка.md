*Cross-validation* — це метод оцінювання моделі, за якого ми декілька разів навчаємо та перевіряємо її на різних частинах одного набору даних.

*Головна мета* — отримати більш надійну оцінку якості моделі, ніж при одному випадковому розділенні.

## K-fold Cross-validation
Це один із найпопулярніших методів валідації. Ми розділяємо весь набір даних на $k$ приблизно однакових частин — *folds (фолдів)*.

Наприклад, якщо $k = 5$, маємо 5 частин даних.

*Як це працює?*
1. Перший раз: 1-ша частина для тестування, решта чотири — для навчання.
2. Другий раз: 2-га частина для тестування, решта — для навчання.
3. Третій раз: 3-тя частина для тестування.
4. Четвертий раз: 4-та частина для тестування.
5. П'ятий раз: 5-та частина для тестування.

Отже, кожна частина один раз побуває тестовою. Після цього обчислюємо середній результат:

$$E = \frac{1}{k}\sum_{i=1}^{k}E_i$$

Де:
- $E$ — середній результат;
- $k$ — кількість фолдів;
- $E_i$ — результат окремого фолду.

*Приклад:* Припустимо, отримали такі значення Accuracy:

| Fold | Accuracy |
| :--- | :------- |
| 1    | 90%      |
| 2    | 92%      |
| 3    | 88%      |
| 4    | 94%      |
| 5    | 91%      |

Середнє:
$$\frac{90+92+88+94+91}{5} = 91\%$$

Отже, середня точність моделі — **91%**.

### Яке значення $k$ вибирати?
- Традиційне значення: $k = 10$.
- Для великих наборів даних: $k = 5$.
- Чим більше $k$, тим більше даних використовується для навчання в кожній ітерації, але тим довше триває обчислення.

*Що буде, якщо $k = N$? Це спеціальний випадок, який називається Leave-One-Out Cross-validation (LOOCV).*

# Leave-One-Out Cross-validation (LOOCV)
*LOOCV* — це метод, при якому для кожної ітерації ми залишаємо рівно один запис для тестування.

Якщо є 100 записів:
- 99 використовуються для навчання;
- 1 використовується для тестування.
- Це повторюється 100 разів.

**Перевага:**
- Майже всі дані використовуються для навчання.

**Недоліки:**
- Потрібно багато разів навчати модель.
- Обчислення може бути дуже дорогим.

# Stratified K-fold Cross-validation
Це вдосконалений варіант K-fold. Його особливість — **збереження пропорцій класів у кожному фолді**.

Уявімо, що маємо набір даних:
- 90% — здорові пацієнти;
- 10% — хворі пацієнти.

При звичайному випадковому розподілі може статися так, що в одному фолді буде дуже мало хворих пацієнтів, а в іншому — більше. Це робить результати оцінювання нестабільними.

**Stratified K-fold** зберігає початкове співвідношення класів: якщо загалом маємо 90% класу A і 10% класу B, то кожен фолд також матиме приблизно 90% A та 10% B.

- **Коли використовувати?** Особливо корисно для класифікації з незбалансованими класами.
